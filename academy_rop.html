«Готовность» = знания (уроки) + навык (тесты с 1-й попытки) + подтверждение (этот КЭВ-чек). Замок 2 открывается только твоей проверкой реального звонка — поэтому грейд Эксперт нельзя «накликать».
🎧 Как проверять: возьми один свежий реальный звонок менеджера (запись в Bitrix), пройди по 8 пунктам каркаса. Обязательный пункт — КЭВ: явное «да» + дата + время + адрес. Без него встреча не назначена — это просто разговор.
